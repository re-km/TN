ひび割れ密度算出 (Crack Density)

DXFファイル（変状展開図）からひび割れデータを抽出し、Excelファイルに転記するツールです。

機能

  • D-STR-TXTレイヤーからS番号（S001〜S409等）を自動検出
  • 寸法線グループ内のS番号にも対応
  • 「0.3mm未満ひび割れ」「0.3mm以上ひび割れ」レイヤーからテキストを抽出
  • ひび割れ長さをmmからm単位に自動変換（例: 550mm → 0.55m）
  • 各S番号の範囲に属するデータをExcelに転記

使用方法

  1. ランチャーの「ひび割れ密度算出」の「起動」ボタンをクリックします（または Crack_Density/ひび割れデータ抽出.bat を実行）。
  2. フォルダ内のDXFファイルとExcelファイルが自動的に読み込まれます。
  3. 処理完了後、同じフォルダに *_出力.xlsx という名前で結果ファイルが生成されます。

入力ファイル要件

  • DXFファイル:
    • レイヤー D-STR-TXT: S番号テキスト
    • レイヤー 0.3mm未満ひび割れ / 0.3mm以上ひび割れ: ひび割れテキスト（例: 0.1×550）
  • Excelファイル: 3行目にS番号がヘッダーとして配置されていること。

入力シート転記 (D-1-1 -> Input Sheet)

トンネル点検調書のExcelデータ（様式D-1-1）を入力シートに転記し、寸法をmmからmに自動変換するツールです。

機能

  • 5桁の数字_D-1-1.xlsm からデータを取り込みます。
  • トンネル点検調書入力シートVer_2（福井県Ver_rebircle）.xlsx に値を貼り付けます。
  • 入力シートのX列にある 数字mm×数字mm 形式のデータを解析し、M列・N列にメートル単位で入力します。

使用方法

  1. D-1-1_2InputSheet フォルダに、転記元の *_D-1-1.xlsm ファイルとテンプレートの 入力シート.xlsx を配置します。
  2. ランチャーの「入力シート転記」の「起動」ボタンをクリックします（または 実行.bat を実行）。
  3. *_トンネル点検調書入力シート.xlsx が生成されます。

様式D-3シート追加 (Sheet Creator)

指定されたExcelファイル（A.xlsx）のデータ量に基づいて、様式D-3シートを自動追加・転記するツールです。

機能

  • xxxxx_A.xlsx のデータ行数をカウント。
  • xxxxx_D-3.xlsm を開き、Excelアドインの「様式D-3シート追加」ボタンを必要な回数だけ自動クリックします。
  • 作成されたシートにデータを転記します。

使用方法

  1. 事前にExcelを手動で起動し、対象の xxxxx_D-3.xlsm ファイルを開いておいてください。
  2. ランチャーの「様式D-3シート追加」の「起動」ボタンをクリックします（または run_sheet_creater.bat を実行）。
  3. 黒い画面（コマンドプロンプト）が表示され、自動処理が始まります。マウス操作などは控えてください。
  4. 「処理が終了しました」と表示されたら完了です。

DXF分割 (DXF Splitter)

複数の図面が統合されたDXFファイルを、個別の図面ファイルに自動分割するツールです。

機能

  • 図面サイズと配置（横並び・縦並び）を自動検出。
  • 図面内のタイトル文字を検出し、ファイル名に自動適用します。
  • 各図面を原点(0,0)に移動して保存します。
  • 図面枠レイヤーを自動的に除外します。

使用方法

  1. DXF2D-2 フォルダに分割したいDXFファイルを置きます。
  2. ランチャーの「DXF分割」の「起動」ボタンをクリックします（または run_splitter.bat を実行）。
  3. [元のファイル名]_split というフォルダが作成され、その中に分割されたDXFファイルが出力されます。

設備数量集計 (Facility Counter)

DXFファイル内のテキスト（設備番号など）を集計し、Excelレポートを作成するツールです。

機能

  • フォルダ内のDXFファイルを一括処理。
  • H001, PB001 などのアルファベットプレフィックスごとに番号を集計。
  • 番号の抜け（欠番）をチェック。
  • facility_counts_report.xlsx に結果を出力。

使用方法

  1. DXF_facility_counter フォルダに対象のDXFファイルを置きます。
  2. ランチャーの「設備数量集計」の「起動」ボタンをクリックします（または run_tools.bat を実行）。
  3. 同じフォルダに facility_counts_report.xlsx が生成されます。

画像修復 (Paint Save)

画像ファイルを読み込み、RGB形式で再保存することで、フォーマット起因のエラー（Error 481など）を修正するツールです。

機能

  • 指定フォルダ内の画像（jpg, png, bmp）を一括処理。
  • CMYKや透過などが含まれる画像を標準的なRGB形式に変換。
  • Exif情報なども正規化され、他のツールで読み込みやすくなります。

使用方法

  1. paint4save/images フォルダに、修復したい・変換したい画像を入れます。
  2. ランチャーの「画像修復」の「起動」ボタンをクリックします（または run.bat を実行）。
  3. paint4save/images_fixed フォルダに、修復済みの画像が保存されます。
